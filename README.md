
# Gleics Clinic

Sistema demonstrativo de atendimento inteligente para uma clínica de estética fictícia, utilizando inteligência artificial para interagir com visitantes e responder dúvidas sobre os serviços.

## Objetivo do projeto

Desenvolver uma aplicação web com um assistente virtual integrado a um modelo de linguagem executado localmente, proporcionando uma experiência de atendimento automatizada.

## Tecnologias utilizadas

### Front-end
- React
- TypeScript
- Vite
- CSS

### Back-end
- Node.js
- Express
- TypeScript
- LangChain
- Ollama
- Llama 3.2

## Funcionalidades

- Interface web para apresentação da clínica.
- Assistente virtual com inteligência artificial.
- Processamento de mensagens por meio de uma API.
- Modelo de linguagem executado localmente.

## Status do projeto

Em desenvolvimento.

## Observação

A Gleics Clinic é uma clínica fictícia criada exclusivamente para fins de demonstração e portfólio.
